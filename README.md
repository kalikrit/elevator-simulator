# Elevator Simulator

Симулятор работы 4 лифтов в 25-этажном доме.  
Реализован на **Vue 3 + Vite + TypeScript**.

## Описание

Интерактивный симулятор, в котором пользователь вызывает лифты на разных этажах. Каждый лифт имеет очередь вызовов и обрабатывает их по порядку. Визуализация показывает движение всех лифтов в реальном времени.

## Функционал

- **Вызов лифта** – на каждом этаже есть круглая кнопка 🛗. При нажатии лифт приезжает на этот этаж, ждёт 5 секунд, затем отвозит пассажира на первый этаж.
- **Очереди лифтов** – каждый лифт обрабатывает поездки последовательно. Все промежуточные этажи добавляются в очередь в порядке следования.
- **Остановка на промежуточных этажах** – при достижении каждого этажа (в том числе промежуточного) лифт стоит 5 секунд (имитация посадки/высадки).
- **Попутный подбор** – если лифт уже движется вниз и проезжает этаж, на котором был сделан вызов, он может подобрать пассажира по пути (остановка будет добавлена в очередь).
- **Визуализация** – отображаются все 25 этажей, положение лифтов, их направление и текущая цель.
- **Статистика** – количество поездок и активных лифтов обновляется в реальном времени.

## Установка и запуск

### 1. Клонирование

```bash
git clone https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/elevator-simulator.git
cd elevator-simulator
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.

### 4. Сборка для продакшена

```bash
npm run build
```

## Как пользоваться

- На каждом этаже есть круглая кнопка 🛗.
- Нажмите на кнопку – лифт приедет на этот этаж.
- После короткой остановки (5 секунд) лифт отвезёт вас на первый этаж.
- Активная кнопка подсвечивается оранжевым (это означает, что вызов принят).
- Если несколько лифтов двигаются, алгоритм выбирает наиболее подходящий.

## Алгоритм управления

- **Выбор лифта**: для каждого вызова вычисляется предполагаемое время прибытия для каждого лифта (с учётом текущей позиции и очереди). Выбирается лифт с минимальным временем.
- **Попутный подбор** (только для спускающихся лифтов): если лифт движется вниз и есть цель ниже текущего этажа, а вызов сделан с промежуточного этажа, то этот лифт может подобрать пассажира по пути. Для движущихся вверх лифтов попутный подбор не разрешён.
- **Очереди**: каждый лифт хранит очередь этажей, которые должен посетить. Очередь всегда отсортирована по направлению движения (для вверх – по возрастанию, для вниз – по убыванию).
- **Движение**: лифты движутся со скоростью 1 этаж в секунду (60 кадров/сек).
- **Возврат на первый этаж**: после выполнения всех поездок лифт возвращается на первый этаж и переходит в состояние ожидания.
